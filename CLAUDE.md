# OTTO Plumbing CRM — Claude entry point

Before doing anything, read in this order:

1. `AGENTS.md`
2. `docs/REPO-CONTROL.md`
3. `docs/STATUS.md`
4. `docs/DECISIONS.md`

`AGENTS.md` contains the permanent safety and working rules. `docs/REPO-CONTROL.md` contains the current objective and priority order.

Do not use old task queues, autonomous loops, historical reports, or chat summaries as current instructions unless `docs/REPO-CONTROL.md` explicitly activates them.

Never hardcode or repeat changing facts such as test totals, commit IDs, branch counts, or current tasks in this file.
