# Borrador de Contrato - OTTO Plumbing Inc.

Este documento sirve como borrador inicial para el acuerdo de desarrollo del proyecto.

## 1. Alcance del Proyecto
* Descripción de los servicios (desarrollo web, sistema CRM).
* Entregables principales.

## 2. Tiempos y Plazos
* Cronograma estimado de fases.
* Fechas de entrega de hitos.

## 3. Condiciones Económicas
* Costo total del proyecto.
* Plan de pagos (anticipo, hitos, entrega final).

## 4. Responsabilidades
* Obligaciones del equipo de desarrollo.
* Obligaciones del cliente (provisión de contenido, aprobaciones).

*(Nota: Este es un borrador para revisión y no constituye un acuerdo legal vinculante hasta su firma final.)*
